THE BASICS

for-loop

TLDR: How your code transforms from human-readable text to machine instructions.

If you've ever written a for loop in Python, you already understand iteration. But underneath, Python goes through multiple stages to translate your logic into something the virtual machine can execute.

Your CPU doesn't understand source code. It can't read variables, parse indents, or understand Python syntax. But it doesn't need to. The Python interpreter acts as the middleman, breaking your code down step by step.

The journey begins with human-readable Python source code.

$ cat loop.py
for i in range(3):
    print(i)

The lexer breaks the raw text into a sequence of tokens.

$ ./python.exe -m tokenize loop.py
0,0-0,0:            ENCODING       'utf-8'
1,0-1,3:            NAME           'for'
1,4-1,5:            NAME           'i'
1,6-1,8:            NAME           'in'
1,9-1,14:           NAME           'range'
1,14-1,15:          OP             '('
1,15-1,16:          NUMBER         '3'
1,16-1,17:          OP             ')'
1,17-1,18:          OP             ':'
1,18-1,19:          NEWLINE        '\n'
2,0-2,4:            INDENT         '    '
2,4-2,9:            NAME           'print'
...

The parser organizes the tokens into an Abstract Syntax Tree (AST).

$ ./python.exe -c "import ast; print(ast.dump(ast.parse(open('loop.py').read()), indent=2))"
Module(
  body=[
    For(
      target=Name(id='i', ctx=Store()),
      iter=Call(
        func=Name(id='range'),
        args=[Constant(value=3)]),
      body=[
        Expr(value=Call(func=Name(id='print'), args=[Name(id='i')]))
      ]
    )
  ]
)

The compiler translates the AST into bytecode instructions.

$ ./python.exe -m dis loop.py
  0           RESUME                   0

  1           LOAD_NAME                0 (range)
              PUSH_NULL
              LOAD_SMALL_INT           3
              CALL                     1
              GET_ITER                 0
      L1:     FOR_ITER                11 (to L2)
              STORE_NAME               1 (i)

  2           LOAD_NAME                2 (print)
              PUSH_NULL
              LOAD_NAME                1 (i)
              CALL                     1
              POP_TOP
              JUMP_BACKWARD           13 (to L1)

  1   L2:     END_FOR
              POP_ITER
              LOAD_COMMON_CONSTANT     7 (None)
              RETURN_VALUE
THE JOKE

fore-loop

TLDR: A custom Python loop that skips ahead by 4. Because it's a "fore" loop! Get it?

Wait, a fore loop? Yes, we modified the actual Python C source code—specifically Grammar/python.gram and Parser/Python.asdl—to add a brand new keyword! It works just like a for loop, except it throws away three items for every one it processes. It steps by four!

After defining the syntax, we told the compiler to generate three extra FOR_ITER instructions to skip the next three items. Let's see how it compiles from start to finish!

We write our custom fore loop, expecting it to step by 4.

$ cat fore_loop.py
fore i in range(10):
    print(i)

The lexer spots our shiny new fore keyword.

$ ./python.exe -m tokenize fore_loop.py
0,0-0,0:            ENCODING       'utf-8'
1,0-1,4:            NAME           'fore'
1,5-1,6:            NAME           'i'
1,7-1,9:            NAME           'in'
1,10-1,15:          NAME           'range'
1,15-1,16:          OP             '('
1,16-1,18:          NUMBER         '10'
1,18-1,19:          OP             ')'
1,19-1,20:          OP             ':'
1,20-1,21:          NEWLINE        '\n'
2,0-2,4:            INDENT         '    '
2,4-2,9:            NAME           'print'
...

The parser creates a custom Fore node in the Abstract Syntax Tree.

$ ./python.exe -c "import ast..."
Module(
  body=[
    Fore(
      target=Name(id='i', ctx=Store()),
      iter=Call(
        func=Name(id='range'),
        args=[
          Constant(value=10)]),
      body=[
        Expr(
          value=Call(
            func=Name(id='print'),
            args=[
              Name(id='i')]))])])

The compiler adds extra FOR_ITER instructions to skip 3 items every time! 🤯
